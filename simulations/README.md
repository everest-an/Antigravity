# simulations/ — 理论模拟附件

论文判决矩阵与 Reality Stack 各层的可计算模拟。与 `../experiments/`（解析核算）互补：
experiments 回答"量级是多少"，simulations 回答"三模型/三理论在同一装置下给出什么不同结果"。

## 运行

```powershell
py 01_gie_protocol.py
py 02_em_field_curvature.py
py 03_entanglement_geometry_toy.py
```

依赖：numpy（01、03 需 scipy 级别矩阵运算；02 仅 numpy）。

## 内容与保真度

| 脚本 | 模拟对象 | 判决矩阵行 | 保真度 |
|---|---|---|---|
| 01 | GIE 协议三模型歧视：量子引力 vs Schrödinger–Newton vs LOCC；负度/CHSH/有限统计 N(3σ) | 6/7 | 玩具精确（四维希尔伯特空间，精确分支相位） |
| 02 | 电磁场 → 时空曲率：FFT 泊松解，含"压强也进 Tμν"的因子 2 | 3/17 | 高（线性化 GR 牛顿极限） |
| 03 | 纠缠 → 几何玩具骨架：1D 自由费米子链面积律 | 18 | 示意性（非预言） |

## 关键结果

- **01**：Bose 基准参数下量子引力产生 N≈0.08 的弱纠缠（CHSH 违背 0.024）；
  Schrödinger–Newton 与 LOCC 严格为零——"观测到纠缠=排除局域经典通道"的逻辑被数值实现。
  有限统计给出 N(3σ)~10³（基准）与 ~10¹⁵（电流芯片参数），与 experiments/01 一致。
- **02**：1 m³、10 MV/m 的电容器产生 ~10⁻²⁵ m/s² 引力（比地球小 25 个数量级）；
  要产生地球级引力需要 ~8 倍 Schwinger 极限的场强——真空在该处已不稳定。
- **03**：1D 基态纠缠熵 S(l) 饱和（面积律骨架），说明"纠缠↔几何"对应在玩具层
  只给出骨架，真实宇宙断言仍是 Level C。

## 方法论备注

- 每个脚本明确标注保真度等级，不把玩具结果当作物理预言；
- 01 的分支相位用精确式（不做小 Δx 展开）——这正是"箭头纪律"在代码里的体现：
  近似在何处失效（Δx~d 时小展开错误达 10³ 倍）是可复现的。
