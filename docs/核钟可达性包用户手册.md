# 核钟可达性包（E2）用户手册

> 面向实验组的"拿来即用"手册。本包用三个脚本回答一个问题：
> **给定你们的钟稳定度与源配置，KK Yukawa 耦合 α 在哪个参数窗口、以多少积分时间可被 5σ 检出？**

- 论文依据：《核钟实验设计方案》v2.0（`paper/核钟实验设计方案.typ`，中英双版）
- 代码：`experiments/14_nuclear_clock_reachability.py`、`15_microscope_kk.py`、`16_signal_simulator.py`
- 依赖：Python 3.10+，仅需 `numpy`（`pip install numpy`）
- 一键回归：`py test_all.py`（应含本包全部脚本）

---

## 1. 物理设定（一句话版）

Kaluza-Klein / Yukawa 型额外引力通道给出势能修正
`V = −(G m₁ m₂/r)(1 + α e^(−r/λ))`。
绕引力体（地球或实验室源）运动的核系统获得能级分裂
`ΔE = m_sys · α · ΔΦ`，其中 `ΔΦ` 由源质量与几何决定。
核钟测的是频率：`y = ΔE/(hν₀)`，`ν₀ ≈ 2.020×10¹⁵ Hz`（Th-229 的 8.3557 eV 跃迁）。

| 配置 | ΔΦ | 信号系数（eV per α） |
|---|---|---|
| 实验室（100 kg 源，0.15→1.5 m 翻转） | `G M (1/r₁ − 1/r₂)` | `s_lab = 9.50×10⁻¹⁴` |
| 轨道（LEO，e=0.01） | `2 g a e ≈ 1.18×10⁶ m²/s²` | `s_orb = 2.79` |

**核心修正（v2.0 关键数字）**：早期版本把轨道系数 `2.8 eV/α` 误用于实验室配置，
导致信号高估 7 个数量级。实验室配置的正确系数是 `9.5×10⁻¹⁴ eV/α`。

## 2. 三个脚本与输出文件

### 2.1 脚本 14 — 可达性全参数扫描（核心）

```powershell
py experiments\14_nuclear_clock_reachability.py
```

输出 `build/reachability_lab.csv`：列 = `λ [m], α_min(投影稳定度, τ=1e6 s)`。
控制台同时打印 τ = 10³~10⁶ s 的 α_min 表（实验室）与轨道配置极限。

- α_min 定义：`α_min = δE(τ) / s × e^(a/λ)`，其中 `δE(τ) = 8.36 eV × σ_y(τ)`（1σ 约定）。
- 投影稳定度：`σ_y(τ) = 4.6×10⁻²³/√τ`；当前平台（kHz 线宽）：`σ_y = 1×10⁻¹⁵`（不随 τ 改善）。

**改参数**：源质量/距离在 `lab_signal_per_alpha()`；稳定度模型在 `sigma_proj`；
λ 网格在 `np.logspace(6, 10, 5)`（单位 m，对应 10³ km ~ 10⁷ km 波长）。

### 2.2 脚本 16 — 信号模拟器（含噪声模型）

```powershell
py experiments\16_signal_simulator.py
```

输出两个文件：

- `build/simulated_signal.csv`：20 轮源翻转的合成频差序列（α=1e-10，τ=1e6 s，投影档）。
- `build/snr_vs_tau.csv`：列 = `τ, 情景, σ_Δy, SNR(α=1e-10), α_min(5σ)`。
  两档情景：`current`（σ_y=1e-15）与 `projected`（σ_y=4.6e-23/√τ）。

- α_min 定义（5σ 约定）：`α_min = 5·√2·σ_y(τ)·E_trans / s_lab`。
- **约定差**：脚本 16 的 5σ 值是脚本 14 的 1σ 值的 `5√2 ≈ 7.07` 倍——这是阈值约定差异，
  不是计算差异（脚本 16 第 [4] 节显式验证比值 = 7.07）。

### 2.3 脚本 15 — MICROSCOPE 公布值对照

```powershell
py experiments\15_microscope_kk.py
```

输出 `build/microscope_alpha_composition.csv`（组分依赖通道的 α_bound(λ) 扫描）。
回答"你们的灵敏度是否优于既有约束"：

- MICROSCOPE 2σ 界（η < 5.5×10⁻¹⁵）只约束**组分依赖**耦合；
- KK 引力子与 Tμν 普适耦合 → 等效原理实验对它的通道**结构性失明**；
- 普适通道的既有约束来自测距（LAGEOS 1e-9@10⁷ m；LLR 3e-11@3.8×10⁸ m；行星历表 1e-8）。
- 对照结论：实验室配置在 λ∈[10⁷, 10¹⁰] m 段深于测距界 1~2 个数量级；
  轨道配置 α_min ~ 1.4×10⁻²⁵（同投影稳定度，τ=10⁶ s），比测距界深约 14 个数量级。

## 3. 结果解读指南

### 3.1 α_min 表怎么读

`α_min(τ, λ) = 2.9×10⁻¹¹`（投影档，τ=10⁶ s，5σ）的意思是：
源翻转实验中，积分 10⁶ s 后能以 5σ 检出的最小耦合为 α ≈ 3×10⁻¹¹。
更小的 α 需要更长的 τ（投影档按 √τ 改善）或更大的源质量（s ∝ M）。

### 3.2 为什么当前平台不可行（重要）

kHz 线宽平台：`α_min(5σ) ≈ 0.6`——O(1) 量级，远劣于既有约束（Eöt-Wash α<10⁻⁶，
LLR 3×10⁻¹¹）。**稳定度是硬前提**：σ_y(τ) 必须达到投影稳定度
4.6×10⁻²³/√τ（τ=10⁶ s 时 ~4.6×10⁻²⁶）后，
实验室配置才开始在 λ∈[10⁷, 10¹⁰] m 段提供优于测距的新灵敏度。

### 3.3 eV 窗口为什么已关闭（常见误解）

Jusufi et al.（arXiv:2502.07613）的 eV/meV 级分裂预言需要 α ~ 0.4 / 10⁻³，
被 LLR/LAGEOS 测距约束排除 7~8 个数量级。**eV 窗口不需要等核钟——它已被现有数据排除。**
核钟的真实价值在 λ∈[10⁷, 10¹⁰] m 普适通道的新灵敏度（配合轨道搭载可达 10⁻²⁵）。

## 4. 把你们的数字接进来（三步）

1. **改稳定度**：脚本 16 的 `SCENARIOS` 字典。把你们的实测 Allan 偏差
   `σ_y(τ)`（或白调频系数 + 闪烁地板）填成 `"ours": {"sigma": lambda tau: ...}`。
2. **改源参数**：脚本 14 的 `lab_signal_per_alpha()`——源质量 `M`、翻转位置 `r1, r2`。
   信号系数按 `s = m_Th · G M (1/r₁ − 1/r₂)/eV` 直接缩放。
3. **重跑三个脚本**：新的 `build/*.csv` 即你们的预算表；
   再对照脚本 15 判断该灵敏度是否优于既有约束（决定新物理价值）。
